# DOCX со статическим оформлением

`static-word-elements.docx` — синтетический воспроизводимый regression fixture.
Генератор: `packages/template-compiler/src/docx-compatibility.test.ts`, тест повторяемой строки,
переменная `DOCOMATOR_COMPAT_FIXTURE_DIR`. Содержит поле подстановки, обычную ссылку,
закладку, поле Word PAGE и встроенную PNG-картинку с корректными CRC.
Никакие внешние документы или данные пользователя не используются.

SHA-256: `63dc0a77df7a76df28f18644eb5715348042a8a7a73229963bf4fe9800bfdd72`.

Проверяется полный путь UI → сохранение без ручных примеров → активация → генерация
двух строк → скачивание и обратное чтение. Содержимое всех частей ZIP, кроме
`word/document.xml`, должно остаться побайтно неизменным.
