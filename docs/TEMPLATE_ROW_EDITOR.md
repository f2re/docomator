# Редактор повторяемой строки Word

Редактор используется, когда в одном сводном DOCX должна появиться отдельная строка таблицы для каждого участника группы.

## Первичная настройка

1. Подготовьте строку заголовков и одну пустую образцовую строку.
2. В структуре шаблона выберите любую ячейку образцовой строки.
3. Нажмите **«Настроить всю строку»**.
4. Для каждой колонки выберите источник:
   - **Номер строки 1, 2, 3…**;
   - **ФИО участника**;
   - существующее поле карточки;
   - новое общее поле;
   - **Не заполнять**.
5. Для ФИО выберите формат записи и порядок частей исходного имени.
6. Отметьте обязательные колонки.
7. Нажмите **«Сохранить настройки строки»**.

## Повторное редактирование

Повторно выберите любую ячейку той же строки и откройте редактор. Все сохранённые связи загружаются в выпадающие списки. Можно:

- перепривязать колонку;
- изменить обязательность;
- изменить формат ФИО;
- исключить колонку через **«Не заполнять»**;
- добавить ранее незаполненную колонку.

Нажатие **«Сохранить настройки строки»** допустимо и тогда, когда связи уже существовали. Сообщение «Выберите хотя бы одну колонку» появляется только если все колонки намеренно переведены в режим **«Не заполнять»**.

## Пустая ячейка

Пустая ячейка уже является целым местом подстановки. Выделять текст в ней не требуется. Значение будет записано только в выбранную ячейку; остальная таблица не изменяется.

## Пробная проверка

После сохранения строки выберите **«Перейти к проверке шаблона»**. Тестовые примеры не относятся к реальным сотрудникам: они временно записываются в безопасную копию и считываются обратно.

Кнопка **«Заполнить безопасными примерами»** создаёт нейтральные значения. Если состав полей изменился после открытия формы, Docomator обновит список, сохранит уже введённые примеры и подсветит добавленные поля.

## Рабочий выпуск

Для повторения строки выберите:

- сохранённую группу или отмеченных участников;
- режим **«Один сводный документ»**.

Перед запуском проверьте счётчик участников группы и обязательные поля. Для больших групп поиск, фильтры и переход между страницами редактора состава не снимают ранее сделанный выбор.

В режиме отдельных документов повторяемая строка не превращается в общий реестр.
