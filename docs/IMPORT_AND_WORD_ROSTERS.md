# Импорт людей, заполненных полей и списков в Word

## Что импортируется

Docomator принимает таблицу CSV или XLSX, а также диапазон, скопированный из Excel или LibreOffice. Первая строка должна содержать названия колонок, каждая следующая строка описывает одного человека.

Пример:

| ФИО | Номер зачётной книжки | Учебная группа | Тема научной работы | Научный руководитель |
|---|---|---|---|---|
| Иванов Иван Иванович | ЗК-001 | М-21 | Оценка точности прогноза осадков | Петров Пётр Петрович |
| Смирнова Анна Сергеевна | ЗК-002 | М-21 | Обработка данных радиозондирования | Сидорова Мария Андреевна |

ФИО становится именем карточки человека. Остальные колонки сопоставляются с полями карточки: существующими либо создаваемыми во время импорта.

## Безопасный порядок импорта

1. Откройте **Сотрудники → Импортировать людей и заполненные поля**.
2. Загрузите CSV/XLSX или выберите **Вставить из Excel** и вставьте диапазон вместе с заголовками.
3. Укажите колонку ФИО и устойчивый ключ. Для регулярных обновлений используйте табельный номер, номер зачётной книжки, рабочую почту или иной неизменяемый идентификатор. ФИО как ключ допустимо только при отсутствии лучшего значения.
4. Проверьте сопоставление каждой колонки. Система учитывает названия, псевдонимы, ранее подтверждённые сопоставления и характер значений.
5. Для новых полей проверьте тип и класс данных. Серия, номер и реквизиты паспорта автоматически предлагаются как особо чувствительные данные.
6. Нажмите **Проверить**. Система выполнит полный импорт внутри транзакции и откатит его, поэтому на этом шаге база не изменяется.
7. Просмотрите точное число новых, обновляемых и ошибочных строк. После этого подтвердите импорт.

Пустая ячейка не стирает прежнее значение. Повторная загрузка с тем же устойчивым ключом обновляет существующего человека, а не создаёт дубликат.

## Списки вариантов и автоматическое пополнение

Для должности, подразделения, учебной группы, статуса и других повторяющихся значений подходит тип **Список вариантов**.

При импорте система собирает уникальные значения из колонки и предлагает их как начальный перечень. Можно выбрать:

- **расширяемый список** — новое значение подтверждается оператором и автоматически добавляется в перечень;
- **закрытый список** — строка с неизвестным значением считается ошибочной и не сохраняется.

Название колонки запоминается как другое название поля. Поэтому последующие файлы с заголовками «Должн.», «Позиция» или иным подтверждённым вариантом сопоставляются автоматически.

## Студенты и темы научных работ

Студента не нужно хранить в одном сложном поле. Надёжная структура состоит из одной карточки человека и отдельных полей:

- ФИО;
- номер зачётной книжки;
- учебная группа;
- тема научной работы;
- научный руководитель;
- курс, кафедра и другие сведения при необходимости.

Такую таблицу можно загрузить файлом или вставить из буфера обмена. Отметьте **Собрать импортированных людей в группу**, например «Студенты — темы научных работ». Эту группу затем можно выбрать для сводного документа или расписания.

## Одна строка Word на каждого студента

Подготовьте DOCX с таблицей, в которой есть строка заголовков и одна образцовая строка данных, например:

| № | ФИО студента | Тема научной работы | Научный руководитель |
|---|---|---|---|
|  |  |  |  |

В мастере шаблона:

1. Откройте структуру DOCX и выберите любую ячейку образцовой строки.
2. Нажмите **Настроить строку** в блоке **Заполнить всю строку как список**.
3. Проверьте предложенные поля для каждой колонки. Для ФИО выберите системное поле **ФИО участника**, для темы и руководителя — соответствующие поля карточки.
4. Нажмите **Связать всю строку** и выполните пробное заполнение.
5. При создании документов выберите группу студентов и результат **Один сводный документ**.

Docomator копирует образцовую строку по одному разу для каждого участника группы, сохраняет оформление Word и подставляет значения из конкретной карточки. Первая версия поддерживает одну повторяемую строку в шаблоне и до 1000 участников.

## Ограничения

- XLSX-импорт читает первый рабочий лист.
- Один импорт содержит до 1000 строк, 100 колонок и 8 МБ.
- Первая строка таблицы должна содержать заголовки.
- В одном шаблоне первой версии поддерживается одна повторяемая область без вложенных повторов.
- Для паспортных и иных особо чувствительных данных класс обработки помогает маскированию, журналированию и локальной обработке, но не заменяет организационные меры защиты.
