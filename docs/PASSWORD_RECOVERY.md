# Код доступа: установка, смена и восстановление

Оформлятор работает в модели доверенного общего рабочего пространства. Это один общий **4-значный код доступа** локального контура, а не IAM с пользователями и ролями. Логин не используется.

## Политика

Код состоит ровно из четырёх цифр `0-9`. Он предназначен как простой барьер от случайного открытия Оформлятора внутри доверенной сети и не заменяет firewall, reverse proxy и HTTPS.

Сам код не хранится. Сохраняется параметризованный scrypt-хэш. Смена или восстановление кода одновременно меняет секрет браузерных сессий, поэтому старые сессии завершаются.

## Первый запуск

Откройте Оформлятор в браузере и задайте четыре цифры. Повторное поле и логин не нужны. После сохранения откроется основное приложение.

## Смена или восстановление забытого кода

На сервере выполните одну и ту же штатную команду:

```bash
sudo /opt/docomator/current/first-run.sh --reset-code
```

Старый код не запрашивается. Helper предложит новый код из четырёх цифр и перезапустит API. Документы, сущности, пространства, шаблоны и настройки не изменяются; завершатся только существующие браузерные сессии.

Эта команда показана также прямо на экране «Код доступа» под пунктом «Не помню код», поэтому для восстановления не требуется искать отдельную инструкцию.

## Автоматизированный ввод

Внутренний compatibility-helper `set-password.sh` сохраняется для upgrade/rollback старых установок. Для автоматизации он принимает `--code-stdin` (legacy `--password-stdin` остаётся алиасом):

```bash
printf '%s\n' '1234' | sudo /opt/docomator/current/set-password.sh --code-stdin
```

Код не следует передавать аргументом командной строки. Новые инструкции и пользовательский интерфейс не должны называть этот механизм паролем или учётной записью.

## После восстановления

Проверьте вход новым четырёхзначным кодом, `/healthz`, `/readyz` и отсутствие самого кода в журнале. Если systemd сообщил об ошибке перезапуска, новый код уже сохранён, документы и данные не изменены; проверьте `journalctl -u docomator-api.service` и восстановите службу обычным способом.
