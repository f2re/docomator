# Общий пароль: установка, смена и восстановление

Оформлятор работает в модели доверенного общего рабочего пространства. Это один общий пароль локального контура, а не IAM с пользователями и ролями.

## Политика

Искусственного требования «не менее 12 символов» нет. Допустима любая непустая строка до 512 Unicode-символов. Интерфейс может рекомендовать осмысленный пароль, но не блокирует оператора дополнительными правилами состава.

Сам пароль не хранится. Сохраняется scrypt-хэш. Смена или восстановление пароля одновременно меняет секрет браузерных сессий, поэтому старые сессии завершаются.

## Первый запуск

Откройте Оформлятор в браузере, задайте общий пароль и повторите его. После сохранения откроется основное приложение.

## Смена пароля на сервере

```bash
sudo /opt/docomator/current/scripts/offline/set-password.sh
```

Для автоматизированного защищённого ввода:

```bash
printf '%s\n' 'новый пароль' | sudo /opt/docomator/current/scripts/offline/set-password.sh --password-stdin
```

Пароль не следует передавать аргументом командной строки.

## Восстановление забытого пароля

```bash
sudo /opt/docomator/current/scripts/offline/reset-password.sh
```

Скрипт явно предупреждает, что старый пароль не проверяется и все браузерные сессии будут завершены. Документы, сущности, пространства и настройки не изменяются.

После восстановления проверьте вход новым паролем, `/healthz`, `/readyz` и отсутствие самого пароля в журнале. `--no-restart` допустим только при обслуживании, когда `docomator-api.service` будет перезапущен вручную.
