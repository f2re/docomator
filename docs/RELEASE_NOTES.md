# Оформлятор 0.6.0

Текущая версия: `0.6.0`.

Статус выпуска: `candidate`

Канал выпуска: `pilot`

Статус: **кандидат на стабильный выпуск**. Номер версии фиксирует состав продукта, но не заменяет целевую приёмку. До успешных актов Debian/Astra Linux, восстановления резервной копии, реального Office-корпуса и P5-приёмки разрешён только контролируемый пилот на обезличенных данных.

Единственный машинный источник версии, статуса и канала — `RELEASE_IDENTITY.json`. `VERSION`, package metadata, lockfile, runtime defaults и текущие выпускные документы проверяются относительно него в CI.

## 2026-08-18 — богатое визуальное представление DOCX/XLSX

- Template Studio получает read-only Visual IR, вычисляемый из неизменяемого content-addressed исходника. HTML/DOM не сохраняется в шаблон и не становится вторым Office renderer.
- DOCX-проекция дополнительно показывает свойства шрифта и абзаца: жирный/курсив, подчёркивание, зачёркивание, цвет и подсветку, семейство и размер шрифта, верхний/нижний индекс, регистр, выравнивание, отступы, интервалы и геометрию страницы.
- Таблицы DOCX отображают ширины колонок, объединения `gridSpan`/`vMerge`, заливку, границы и вертикальное выравнивание ячеек. Сохранены существующие DOM-hooks редактора повторяемой строки.
- Основной текст, верхние/нижние колонтитулы, сноски и концевые сноски остаются отдельными областями документа. Безопасные встроенные PNG/JPEG/GIF/WebP показываются из локального OOXML-пакета; внешние связи не загружаются.
- XLSX теперь имеет Excel/Calc-подобную сетку: листы, размеры строк/столбцов, объединения, шрифты, заливки, границы, выравнивание, перенос текста, распространённые числовые/процентные/дата-время форматы, печатные колонтитулы и raster drawing anchors.
- Формулы XLSX показываются с последним сохранённым значением и специальным маркером, но не превращаются в заменяемые поля. Привязка обычной ячейки остаётся прежней серверно проверяемой координатой.
- Direct selection DOCX по-прежнему преобразуется только в `elementId + UTF-16 offsets`; backend повторно сверяет SHA/структуру перед безопасной `w:sdt`-компиляцией.
- Visual endpoint жёстко space-scoped, read-only и `no-store`; он повторно выполняет intake/structure validation, ограничивает размер XML/media и не читает внешние relationship target.
- При невозможности построить rich-проекцию данные не меняются: DOCX остаётся на безопасной базовой проекции, XLSX — на прежнем cell-view, а интерфейс предлагает подтвердить точный вид пробной копией.
- Добавлены минимальные OOXML regression fixtures для Word и Excel, Chromium-проверки computed styles/merge/media/header-footer/320 px и автоматическая публикация фактических скриншотов Template Studio как CI artifact.
- Браузерная проекция намеренно не объявляется пиксельно идентичной Word/Excel: точная пагинация, плавающие DrawingML/SmartArt/OLE, сложные chart/shape объекты, тема-зависимые свойства и окончательный layout подтверждаются пробной копией, LibreOffice PDF и реальным Office-корпусом.
- Новая обратно совместимая возможность повышает версию `0.5.0 → 0.6.0`; статус остаётся `candidate / pilot`.

## История продуктовой линии

- `0.5.0` — безопасная визуальная разметка DOCX v1: основной текст, колонтитулы, сноски, обычные таблицы, bold/italic, direct selection и сохранение прежнего deterministic renderer.
- `0.4.0` — ГОСТ/ЕСКД formatter, публикации/BibTeX/CSL, публичный stateless `/gost`, password reset и связанные regression tests.
- `0.3.1` — структурированные адресные ошибки CSV/XLSX-импорта, частичный импорт корректных строк и явный recovery для legacy `.xls`.
- `0.3.0` — первичная настройка общего пароля в браузере и headless recovery-скрипт.
- `0.2.1` — единая бренд-система рабочего интерфейса и закреплённые 44 px touch targets.
- `0.2.0` — начало SemVer-линии и CI policy для product-changing PR.
- `0.1.0` — исторический baseline первой эксплуатационной линии.

Подробная история каждого изменения остаётся в Git и соответствующих pull request; текущие ограничения и доказательства выпуска описаны в `SUPPORT_MATRIX.md`, `FINALIZATION.md` и `VISUAL_TEMPLATE_STUDIO.md`.
