# Группы полей карточек и шаблонов

## Почему поля смешивались

Ранее все сведения преподавателей и студентов относились к одной сущности `person`. При создании нового свойства система искала существующее поле только по нормализованному названию. Поэтому одноимённые поля, например «Группа», могли ошибочно использовать одну техническую привязку, хотя смысл у них различался.

## Поддерживаемые группы

- **Общие сведения** — ФИО, телефон, электронная почта и другие поля, применимые ко всем карточкам.
- **Преподаватель** — кафедра, должность, учебная нагрузка, учёная степень и другие сведения преподавателя.
- **Студент** — учебная группа, курс, зачётная книжка, тема работы и другие сведения студента.
- **Не распределено** — поля, созданные до введения групп.

Название поля больше не определяет его идентичность самостоятельно. Повторно используется только свойство с тем же названием, типом и группой. Поэтому «Группа» преподавателя и «Группа» студента остаются разными свойствами.

## Работа в редакторе шаблона

Перед выбором поля оператор указывает, к кому относится значение. Список после этого показывает:

1. общие сведения;
2. поля выбранной группы;
3. прежние нераспределённые поля отдельным блоком.

Поля противоположной группы не участвуют в автоматических предложениях. Для строк таблицы группа задаётся отдельно для каждой колонки. Например, «Тема научной работы» относится к студенту, а «Научный руководитель» — к преподавателю.

Нераспределённое поле можно выбрать в конкретной группе. После подтверждения его классификация сохраняется, при этом существующие значения и остальные правила проверки не изменяются.

## Поиск в списках

Большие списки полей используют локальный селект с поиском. Поиск выполняется по:

- названию;
- псевдонимам;
- названию группы.

Управление доступно мышью и клавиатурой: стрелки перемещают фокус, Enter выбирает единственный или активный вариант, Escape закрывает список. Исходный HTML `select` сохраняется для совместимости с формами и автоматическими проверками.

## Совместимость

Новые SQL-таблицы не требуются: группа хранится в метаданных проверки свойства. Старые записи без группы считаются нераспределёнными и не объединяются автоматически с новыми преподавательскими или студенческими полями.
