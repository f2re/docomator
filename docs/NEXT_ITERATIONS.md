# Следующие итерации

Текущая версия: `0.7.0`.

Статус: `candidate / pilot`.

`0.6.4` закрыл пользовательский разрыв доступа: первый запуск задаёт один общий 4-значный код без логина/пароля, старый `/login` только переводит на новый PIN-экран, действующая session не требует повторного ввода, а экран проверяется на 320 px и с экранной/обычной клавиатурой. `0.6.5` исправил выявленный в реальном использовании разрыв шаблонизатора: все поля сотрудников текущего пространства доступны при сопоставлении, а выбор параметра работает обычной прокруткой и клавиатурой без обязательного поиска. `0.6.6` исправил рабочую компоновку самого сопоставления: документ и форма не конкурируют за ширину, а длинный список не выходит за границы инспектора. `0.6.7` закрыл подтверждённые UX-разрывы выпуска: единая шкала шагов, одно доминирующее действие, searchable-select для шаблона/группы и безопасный повтор после ошибки без потери подготовленного состава. `0.6.8` устраняет глобальный result bypass: persisted результаты работают только в явном текущем `space context`, а переключение A → B не принимает поздний ответ A. Граница shared trusted workspace и ADR-0011 не меняются.

## Ограничение объёма разработки

Новые продуктовые функции не добавляются вне дефектов, выявленных реальным target/Office/P5-потоком. Такой дефект исправляется по первопричине и получает regression coverage; сквозной сценарий является частью доказательства исправления, а не отдельным расширением продукта.

Applied migrations не переписываются, граница shared trusted workspace не меняется, микросервисы/облачные зависимости/новый frontend framework не вводятся.
