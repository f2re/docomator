Статус: `candidate / pilot`.

Продуктовый код основного сценария доведён до code-complete состояния. `0.6.1` закрывает оставшийся пользовательский разрыв мастера шаблона: форматированное DOCX/XLSX представление доступно локально, сохраняет CSP без `unsafe-inline`, не исполняет содержимое Office и не меняет детерминированный renderer.

## Ограничение объёма разработки

До появления дефекта, выявленного target/Office/P5-приёмкой, новые продуктовые функции не добавляются. Реальный дефект исправляется по первопричине и получает regression coverage в соответствии с обычной политикой проекта; отдельное расширение E2E/regression inventory не является текущей самостоятельной задачей по решению владельца.

Applied migrations не переписываются, граница shared trusted workspace не меняется, микросервисы/облачные зависимости/новый frontend framework не вводятся.
