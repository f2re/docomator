# ADR-0009: Общий пароль входа в доверенном контуре

Статус: заменено ADR-0011

Дата: 2026-08-08

> Историческое решение. С 2026-08-21 пользовательская модель общего пароля заменена ADR-0011 на единый четырёхзначный код доступа без логина/учётной записи. Физические имена из миграции 0031 сохраняются только из-за неизменяемости применённых миграций.

## Контекст

ADR-0006 закрепил эксплуатацию Оформлятор без встроенной аутентификации: безопасность обеспечивалась внешним доверенным сетевым и системным периметром. Для фактической эксплуатации этого недостаточно: открытие веб-интерфейса по адресу приложения не должно немедленно давать доступ к рабочим данным.

При этом проекту по-прежнему не нужны пользователи, роли, персональные кабинеты и разграничение прав внутри приложения. Пространства остаются организационными границами данных, а не ACL.

## Историческое решение

ADR-0009 ввёл один общий пароль приложения.

- Все интерактивные UI-страницы и предметные API требовали успешного входа.
- `/healthz` и `/readyz` оставались без входа для systemd, reverse proxy и target acceptance.
- В приложении не создавались пользователи, роли, профили и отдельные права.
- Секрет хранился только как scrypt-хэш с солью и параметрами.
- Успешный вход создавал подписанную сервером `HttpOnly`, `SameSite=Strict` cookie с ограниченным сроком действия.
- Password gate считался дополнительным слоем к firewall/reverse proxy/bind address, а не заменой внешнего периметра.

## Историческая первичная настройка

Новая установка генерировала session secret, но пароль задавал первый оператор в браузере. Credential записывался атомарно в SQLite. Локальный `set-password.sh` использовался для recovery и ротации session secret.

Эта схема была trust-on-first-use внутри доверенного контура и не являлась IAM.

## Причина замены

Термины «вход», «логин» и «пароль» создавали неверную продуктовую семантику полноценной аутентификации и усложняли первый запуск и восстановление. Владелец продукта утвердил более точную модель: общий четырёхзначный код как простой барьер от случайного доступа.

Действующее решение, ограничения совместимости и recovery описаны в [ADR-0011](0011-shared-access-code-gate.md).
