# Быстрый старт Docomator

## Для пользователя

Первый рабочий маршрут:

```text
раздел данных → сотрудники/объекты → шаблон → проверка полей
→ пробное заполнение → активация → создать документы → результат
```

1. Откройте Docomator в браузере и выберите нужный раздел данных.
2. Добавьте сотрудников или объекты вручную либо через импорт CSV/XLSX.
3. Откройте «Шаблоны», загрузите DOCX/XLSX и выполните проверку.
4. Свяжите изменяемые места документа с полями данных.
5. Выполните пробное заполнение и исправьте отмеченные проблемы.
6. Активируйте проверенную версию шаблона.
7. Откройте «Создать документы», выберите шаблон и состав.
8. Запустите формирование и скачайте результат в разделе «Результаты».

Подробное руководство доступно в интерфейсе через «Помощь» и в [`USER_GUIDE.md`](USER_GUIDE.md).

## Простая автономная установка

Распакованный комплект можно запускать из обычного каталога. Его не требуется предварительно переносить в каталог `root:root` только ради установки: `install.sh` сам проверяет содержимое комплекта до системных изменений.

```bash
cd /путь/к/docomator-<version>-linux-<arch>
sudo ./install.sh
```

Если комплект содержит согласованный набор системных `.deb` для первой установки:

```bash
sudo ./install.sh --install-os-packages
```

После установки:

```bash
systemctl --no-pager --full status docomator-api.service docomator-worker.service
curl --fail --silent http://127.0.0.1:8080/readyz
```

## Обновление

Используйте `update.sh` из **нового проверенного комплекта**:

```bash
cd /путь/к/новому/docomator-<version>-linux-<arch>
sudo ./update.sh
```

Обновление разрешено и тогда, когда номер `VERSION` совпадает с установленным. Конкретные сборки различаются по SHA-256 `release.json`; прежняя сборка сохраняется для безопасного отката.

Версия продукта меняется только в корневом [`VERSION`](../VERSION). Полный договор — [`VERSIONING.md`](VERSIONING.md).

## Где находятся данные

По умолчанию:

```text
/opt/docomator/current            текущая сборка
/opt/docomator/releases/           immutable-сборки
/etc/docomator/docomator.env       настройки
/var/lib/docomator/docomator.db    SQLite
/var/lib/docomator/objects/        исходные и сформированные файлы
/var/lib/docomator/backups/        резервные копии
```

Для нестандартных путей используйте параметры `--install-root`, `--data-dir` и `--config-dir`.
