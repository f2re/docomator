# Быстрый старт Docomator

Это краткий маршрут от пустой системы до первого готового документа. Полное описание всех вариантов находится в [руководстве оператора](USER_GUIDE.md), а подробности массового импорта и таблиц Word — в [отдельном руководстве](IMPORT_AND_WORD_ROSTERS.md).

## Что должно быть подготовлено

До начала работы нужны:

- запущенные API и рабочий процесс Docomator;
- раздел данных, например «Сотрудники» или «Студенты»;
- таблица CSV/XLSX либо данные, которые можно скопировать из Excel или LibreOffice;
- шаблон DOCX или XLSX;
- понятный устойчивый идентификатор человека: табельный номер, номер зачётной книжки, рабочая почта или другой неизменяемый код.

## Первый рабочий сценарий за 15 минут

### 1. Выберите раздел данных

Откройте **Сотрудники** и выберите нужный раздел. Раздел изолирует карточки людей, группы, шаблоны и результаты одного рабочего процесса от другого.

Для студентов разумно создать отдельный раздел «Студенты», для кадровых документов — «Сотрудники».

### 2. Импортируйте людей и заполненные поля

Нажмите **Импортировать людей и заполненные поля**.

Выберите один из вариантов:

- **Файл CSV или XLSX** — загрузите таблицу;
- **Вставить из Excel** — скопируйте диапазон вместе с заголовками и вставьте его в форму.

Минимальный пример:

```text
ФИО	Табельный номер	Должность
Иванов Иван Иванович	T-001	Инженер
Петрова Анна Сергеевна	T-002	Бухгалтер
```

Для студентов:

```text
ФИО	Номер зачётной книжки	Учебная группа	Тема научной работы	Научный руководитель
Иванов Иван Иванович	ЗК-001	М-21	Оценка точности прогноза осадков	Петров Пётр Петрович
```

### 3. Проверьте основные колонки

Укажите:

- колонку с ФИО;
- колонку, по которой система узнает прежнюю карточку при следующем импорте.

Не используйте должность, подразделение или тему работы как идентификатор: эти сведения могут изменяться. ФИО допустимо как временный вариант, но для регулярного обновления лучше отдельный номер.

### 4. Проверьте сопоставление полей

Для каждой колонки система предложит:

- существующее поле карточки;
- создание нового поля;
- тип значения;
- класс данных;
- варианты перечня, если значения повторяются.

Паспортные реквизиты, СНИЛС и адрес регистрации должны иметь класс **Особо чувствительные данные**. Должность, подразделение, группа и статус обычно удобнее хранить как **Список вариантов**.

### 5. Выполните предварительную проверку

Нажмите **Проверить**.

На этом шаге система ничего не сохраняет. Она покажет:

- сколько карточек будет создано;
- сколько обновится;
- сколько останется без изменений;
- какие строки содержат ошибки.

Исправьте ошибки в исходной таблице или настройках и повторите проверку.

### 6. Подтвердите импорт

Нажмите **Импортировать**. При необходимости заранее включите **Собрать импортированных людей в группу**.

Группа понадобится, чтобы сформировать один документ на каждого человека или один сводный документ со всеми участниками.

### 7. Добавьте шаблон

Откройте **Шаблоны**, загрузите DOCX или XLSX и дождитесь проверки структуры.

Выберите изменяемые места и свяжите их с полями карточки. Например:

- «ФИО» → ФИО участника;
- «Должность» → Должность;
- «Дата рождения» → Дата рождения.

Для таблицы Word с одной строкой на человека выберите ячейку образцовой строки и нажмите **Настроить строку**.

### 8. Выполните пробное заполнение

Введите примеры для всех полей и создайте проверочную копию. Откройте результат в Word или LibreOffice и проверьте:

- правильность значений;
- сохранность оформления;
- формат ФИО и дат;
- повтор строки таблицы;
- отсутствие лишних пустых строк.

После успешной проверки активируйте шаблон.

### 9. Создайте документы

Откройте **Создать документы** и выберите:

- активный шаблон;
- группу либо отдельных людей;
- режим результата.

Доступны два основных режима:

- **Отдельный документ для каждого участника** — договоры, справки, уведомления;
- **Один сводный документ** — реестр, список студентов, таблица тем, общий протокол.

Перед запуском система проверит обязательные значения. Пропуски можно заполнить в форме быстрого исправления, после чего проверку следует повторить.

### 10. Получите результат

После завершения задания откройте результаты, скачайте готовый файл или архив и проверьте его. Результаты сохраняются в системе до скачивания или удаления оператором.

## Как обновлять ранее импортированных людей

Загрузите новую версию таблицы с той же колонкой идентификатора. Система:

1. найдёт прежнюю карточку;
2. обновит только непустые значения;
3. не удалит данные из-за пустой ячейки;
4. создаст карточку только для нового идентификатора;
5. покажет точный план до сохранения.

## Как получить одну строку Word на каждого студента

В шаблоне должна быть строка заголовков и одна образцовая строка данных:

| № | ФИО студента | Тема научной работы | Научный руководитель |
|---|---|---|---|
|  |  |  |  |

В мастере шаблона выберите любую ячейку второй строки, нажмите **Настроить строку**, свяжите все колонки и сохраните. При создании документа выберите группу студентов и режим **Один сводный документ**.

## Что делать при ошибке

Сначала определите этап:

- файл не читается — проверьте формат, размер и первый лист XLSX;
- колонка сопоставлена неверно — выберите поле вручную;
- строка не импортируется — откройте сообщение с номером строки;
- шаблон не связывается — выберите обычный текст или ячейку без формулы;
- сводная таблица не повторяется — используйте режим одного сводного документа;
- запуск заблокирован — заполните обязательные поля всех участников;
- готовый файл не открывается — сохраните идентификатор операции и обратитесь к администратору.

Подробный разбор находится в разделе [Диагностика](USER_GUIDE.md#диагностика-и-типовые-ошибки).
